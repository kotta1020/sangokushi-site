# 三国志 ── 人で読む、九十六年

作成日: 2026-08-16

黄巾の乱（184年）から晋の統一（280年）までを、年号ではなく人間ドラマで読む
初心者向けのサイトです。小説『三国志演義』を軸に、史実とちがうところは注記を入れています。

## 開きかた

`index.html` をダブルクリックすればブラウザで開きます。

うまく表示されないときは、簡易サーバー経由で開いてください。

```bash
cd sangokushi-site && python3 serve.py
```

そのあとブラウザで `http://127.0.0.1:8932/` を開きます。
止めるときはターミナルで `control + C`。

## しかけ

- 本文の**赤い下線の名前**を押すと、その人の肖像とカードがその場で開く（ページは移動しない）
- 本文の**点線の言葉**を押すと、官職や地名の説明が開く
- 各章に「この章の勝負」の表。誰と誰が戦って、どちらが勝ったかが顔つきで並ぶ
- 図鑑は勢力タブ（魏・蜀・呉・群雄・女性）と名前検索つき
- 金色のわくは「ここは物語（演義）の作り話です」の印
- 章の扉と本文に絵が入る。各章の頭に「この章の舞台」（古地図風の絵＋その時点の勢力図）
- 大きな戦いは「動く戦場図」へのリンクつき
- 武将カードの下に「この人の関係」。押すと相手のカードに飛ぶ

## 人物データの直しかた

文章を直したいときは `assets/data/bushou.js` を開いてください。
一人ぶんがこの形で並んでいます。

```js
{
  id: "曹操",          // 名前。本文のリンクはこの名前で人を指している
  yomi: "そうそう",
  file: "sosou",        // 肖像画のファイル名（英字）
  side: "gi",           // gi=魏 shoku=蜀 go=呉 gunyu=群雄 josei=女性
  bu: 71, sei: 97,      // 戦闘力 / 政治力
  lead: "...",          // 一行紹介
  toku: "...",          // 特徴
  kou:  "...",          // おもな手がら
  shu:  "...",          // 最期
  drama:"...",          // この人のドラマ（いちばん読ませたい文）
  ch: [1,2,3,4,5,6]     // 登場する章
}
```

`id` を変えると本文のリンクが切れます。名前を変えるときは、
`story/` の中の `data-p="古い名前"` も一緒に直してください。

## 戦闘力・政治力について

100点満点で、**女性をのぞく61人の平均がちょうど50点**になるよう調整してあります。
つまり50点は「この時代の武将として平均的」という意味で、
低い数字は弱いという意味ではありません（諸葛亮の戦闘力は8点ですが、政治力は100点です）。

数字はこちらで決めた目安です。正解があるものではないので、
納得できないところは自由に書き換えてください。

## 肖像画

画像生成AIで作りました。水墨画風で統一し、指示文は英語で、
年齢・体格・武具・表情・髪とひげだけを人ごとに変えています。

**すべて想像で描いたものです。** 千八百年前の人たちの実際の顔は記録に残っていません。
その旨は図鑑ページとフッターにも書いてあります。

## 元にした資料

魏・蜀・呉それぞれ15人ずつをまとめた手元の資料（計45人）。
ここに群雄16人と女性20人を足して81人にしました。

## 動く戦場図について

`kassen.html` で、十の戦いを一場面ずつ動かして見られます。
「再生」を押すと約6.5秒ごとに場面が進み、部隊が動きます。

図の左上の札が、その場面の**季節と時間帯**です。
空の色、太陽や月、雪や雨、舞い散る花びらや落ち葉も、それに合わせて変わります。

内容を直したいときは `assets/data/kassen.js` を開いてください。
画面は 1000 × 560 のマス目で、左上が (0,0)、右下が (1000,560) です。
`steps` のひとつが一場面で、`move` に書いた座標へ部隊が動きます。
`text` がそのまま画面下の説明文になります。

戦場図は位置関係と動きをつかむための図で、実際の地形や距離とはちがいます。

## 章に入れた絵について

章の絵（桃園、洛陽炎上、赤壁の火など）は、すべて想像で描いたものです。

各章の頭にある「この章の舞台」の勢力図は、その章の年に合わせて塗り分けてあります
（184年・190年・197年・200年・208年・220年・263年の7枚）。
中身は `assets/data/map.js` の `MAP_YEARS` です。

以前は古地図風の絵も入れていましたが、雰囲気だけで情報がないため外しました。
画像は `_archive/scenes-unused/` に残してあります。

## 人物関係図について

`kankei.html` です。真ん中の人から線が伸び、線の色が関係の種類を表します。
**まわりの顔を押すと、その人が真ん中に来ます。** そうやって人から人へたどれます。

関係の種類は13通り。主君と家来／義兄弟／親子／きょうだい／夫婦／親せき／
師と弟子／友／好敵手／討った・討たれた／戦って勝った・負けた／親のかたき／仲が悪い。

**ラベルは「真ん中の人から見て、相手が何にあたるか」**を出します。
曹操を真ん中にすれば夏侯淵は「家来」、夏侯淵を真ん中にすれば曹操は「主君」です。
親子・きょうだい・夫婦は、相手の性別に合わせて
父／母／息子／娘、兄／姉／弟／妹、妻／夫 と出し分けています。

関係を足したり直したりするときは `assets/data/kankei.js` を開いてください。
一行がひとつの関係です。

```js
["劉備","gikyodai","関羽","桃園で誓った兄弟。血はつながっていない"]
//  A      種類      B       ひとこと
```

向きのある関係（主君・親子・師弟・討った）は、
かならず「Aが Bの主君」「Aが Bの親」「Aが Bを討った」の向きで書いてください。
逆向きの言葉（家来・子・弟子・討たれた）は、サイト側で自動で出しています。

いまは81人で120の関係。全員が最低ひとつは関係を持っています。
